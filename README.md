# AutoScientists coordination testbed

A deterministic reference implementation of five coordination mechanisms
from [AutoScientists](https://arxiv.org/abs/2605.28655). A bounded numerical
simulation compares coordinated teams with a single-thread baseline and
measures the effect of removing individual mechanisms.

Start with the [documentation](docs/README.md) for setup, experiments, and
tests, or read the [manuscript](docs/manuscript/README.md).

## What it honestly shows

On the synthetic objective, both configurations reach the same clean
optimum with a clean-metric difference of zero. The dead-end registry cuts
redundant evaluations and stops early. Noise-band confirmation cuts the gap
between the reported and clean metric. The [results guide](docs/results.md)
records all four ablations and the limits of the comparison.
